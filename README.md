# Addition of 2 Values

This repository contains a simple Python program that adds two numbers entered by the user.

## Topics Covered

- Basic Python input
- Arithmetic operations (`+`)
- Printing output

## Description

This program takes two numbers from the user, adds them using the `+` operator, and displays the result.  
It is a beginner-friendly example to practice input, calculation, and output in Python.

## Files

- `prog01.py` – Python program to add two numbers

## How the Program Works

1. Ask the user to enter the first number.
2. Ask the user to enter the second number.
3. Convert the inputs to numbers (integers or floats).
4. Add the two numbers.
5. Print the result.

## Example

```python
a = 5
b = 7
sum = a + b
print(f"The sum is: {sum}")
```

## Output

```text
The sum is: 12
```

## Usage

1. Run the program:
   ```bash
   python prog01.py
   ```
2. Enter the first number.
3. Enter the second number.
4. See the sum printed on the screen.

## Learning Goals

- Understand how to take user input in Python
- Learn how to perform arithmetic operations
- Practice printing results
- Build a foundation for more complex programs

## Conclusion

This repository is useful for beginners who want to learn basic Python input, calculation, and output using a simple addition program.
